PIPELINE COMPLET : mesures -> graphes -> archive
================================================
Copier ce dossier dans yolo_hw\pipeline (pipeline_complet.ps1 + config_puissance\) ;
make_figures.py est cherche dans ce dossier, puis dans sw_sd ou yolo_hw (le copier a cote si besoin).

Prerequis : carte branchee (JTAG + USB serie), vitis_ws deja construit (build_app / build_yolo / build_yolo_sd deja faits),
model.bin dans sw_net, carte SD (volume BOOTFS) avec images\ , xsct accessible, python + pyserial inutile (port serie .NET).

Tout faire :
  cd C:\Users\USER\Desktop\yolo_hw\pipeline
  powershell -ExecutionPolicy Bypass -File .\pipeline_complet.ps1 -Port COM5
Avec puissance (wattmetre USB) :
  powershell -ExecutionPolicy Bypass -File .\pipeline_complet.ps1 -Port COM5 -Puissance
Seulement certaines etapes :
  ... -Etapes figures,archive          (refaire graphes + zip a partir des logs les plus recents)
  ... -Etapes couches,reseau,figures
Ce que fait le script : 1 test des 21 couches ; 2 reseau complet par couche (hash a verifier) ; 3 benchmark SD ARM seul vs ARM+IP
(il vous guide pour les allers-retours de la carte SD) ; 4 puissance (option) ; 5 copie du rapport Vivado ; 6 graphes ; 7 archive
yolo_hw\envoi_rapport_<date>.zip contenant figures, chiffres_cles.txt, logs, resultats. Envoyer ce zip.
Garanties : l'ancien dossier out\ de la carte est renomme, jamais efface ; pour la puissance les images en trop sont deplacees puis remises ;
tout echec (hash different, TOUT OK absent, sorties differentes) est signale en jaune et note dans resume_pipeline.txt.
Non fait par le script (volontairement) : recompilation Vitis (il faut vider vitis_ws, voir les scripts build_*.tcl).
